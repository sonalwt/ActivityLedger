ActivityWatch Sync Setup

Download Your Setup Files

1. Download sync.ps1 2. Download AW-Sync.vbs

Optional: Visible Runner (for testing)

Setup Instructions (2 Easy Steps)

Step 1: Save Files Together
  1. Create a folder: C:\ActivityWatchSync\
  2. Save sync.ps1 into this folder
  3. Save AW-Sync.vbs into the same folder
Step 2: Add to Windows Startup
  1. Press Win + R
  2. Type shell:startup and press Enter
  3. Copy AW-Sync.vbs into the Startup folder
  4. Done! Sync will auto-start on next login
Important: Keep sync.ps1 in C:\ActivityWatchSync\ — the VBS file looks for it there.
If you want a different folder, edit the path in AW-Sync.vbs.
How to verify it's running:
  • Open Task Manager (Ctrl+Shift+Esc)
  • Go to "Details" tab
  • Look for powershell.exe running
  • Or check the dashboard for your activity data
To test manually: Double-click run_sync_visible.bat to see sync output in a window.
